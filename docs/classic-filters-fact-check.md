# Classic filter fact check

Verified on 2026-09-30 against research papers, author accounts, institutional records, and library documentation.
This record covers all 35 entries in `data/classic/classic.filters.seed.json`.

## Interpretation

- `releaseDate` records the cited publication or presentation year, using `YYYY` when a precise day is not established.
- Generic methods with no verified single inventor or introduction date use `null` for their historical metadata.
- A mathematical namesake does not establish who introduced its digital image-processing implementation.
- `country` refers to the research location associated with the cited work, usually the first author's affiliation, rather than nationality or conference location.
- `kernelBased` includes spatial filtering and structuring-element operations within a larger algorithm.
- `kernelSizes` lists documented example supports, not an exhaustive list of allowed sizes.
- Empty kernel sizes with `kernelBased: true` mean the support depends on scale or implementation and no fixed support is asserted.
- Linearity describes the named operation before optional thresholding, magnitude calculation, feature selection, or histogram pooling.
- Outputs distinguish derivative/filter response images from thresholded edges and detected keypoints.
- `requiresTraining` includes model fitting required on the input image, so GrabCut is true because it fits foreground/background Gaussian mixtures.
- FAST and ORB remain false because their supplied detectors/descriptors do not require the caller to train them.
- Frameworks are a conservative list of verified implementations, not every library capable of implementing the algorithm with custom code.
- `opencv` includes its contributed `xfeatures2d` module for BRIEF and SURF; SURF requires a build with `OPENCV_ENABLE_NONFREE`.
