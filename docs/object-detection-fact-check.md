# Object Detection seed fact check

Reviewed on 2026-09-30 against original papers, author repositories, release records, and model cards.
The audit covers all 28 entries originally present in `data/classic/classic.object-detection.seed.json`.
YOLO-NAS was removed by a concurrent catalog edit during the review and has not been restored.

Dates identify the first public introduction for architectures and families, and the original checkpoint release for named trained models.
They do not identify later framework ports or conference presentation dates.
Dataset lists name documented training or backbone pretraining datasets, are not exhaustive, and do not include datasets used only for evaluation.
For architectures and families, the lists can cover multiple published variants rather than a single checkpoint.
`open` describes publicly distributed weights under an open license, including copyleft licenses; it does not promise unrestricted commercial use.
Abstract architecture entries use `not-applicable` because the architecture itself has no particular weights, even when its published implementations provide pretrained models.
`realTimeCapable: true` means at least one documented variant has a real-time benchmark on the source's hardware, not that every variant runs in real time on every device.
Unresolved real-time capability remains `null`.
Providers identify the releasing organization or lead research institution; countries retain that organization's country convention rather than claiming every collaborator is located there.
IDs, family tokens, aliases, category slugs, and `minPool` also serve game identity, search, and difficulty purposes.
The difficulty values are editorial settings, not externally verifiable model properties.

## Interpretation notes

The Grounding DINO release timestamp was checked through GitHub's public release API: `published_at` is `2023-04-07T09:36:20Z` for `v0.1.0-alpha2`.
Florence-2 Large's public commit API records `add_model (#1)` at `2024-06-15T01:00:03.000Z`, matching the visible upload history.
YOLOv5's current comparison documentation cites 2020-06-26, but its original release notes explicitly record public availability on 2020-05-27; the first-public-release convention uses the earlier documented milestone.
SSD was collaborative work involving UNC Chapel Hill, Google, University of Michigan, and, in the revised paper, Zoox; the provider field lists those collaborating institutions.
Ultralytics' [company page](https://www.ultralytics.com/about) lists its US location alongside several international offices, supporting retention of the existing US provider-country convention.
OWL-ViT's detection datasets are documented even though its large-scale web image/text pretraining corpus is not fully enumerated here.
YOLO-NAS's [weights license](https://github.com/Deci-AI/super-gradients/blob/master/LICENSE.YOLONAS.md) restricts commercial use, redistribution, and modification; SuperGradients' code license must not be substituted for the weights license.
The concurrent Computer Vision review supplies verified broader family capabilities and shared provenance.
Category-specific dataset and architecture lists can differ in detail without claiming exhaustive coverage.
Shared facts are synchronized between both source files before regenerating the combined catalog.
The combined Classic and Timeline seeds are regenerated through the existing merge scripts.
