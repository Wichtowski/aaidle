# Computer Vision seed fact check

Reviewed on 2026-09-30 using original papers, author repositories, model cards, and release records.
This review covers all 65 entries currently in `data/classic/classic.computer-vision.seed.json`.
YOLO-NAS was removed by a concurrent catalog edit and has not been restored.

## Interpretation

Dates identify the first public introduction of architectures and families, or an original checkpoint release when an explicit release record is available.
Paper submission dates remain introduction dates where the original checkpoint publication cannot be independently dated.
A year replaces an invented day when the evidence supports only that precision.
Framework ports and conference dates do not replace the original introduction.

Architecture entries use `not-applicable` for weight availability and license because an abstract architecture has no single checkpoint or implementation license.
This does not mean public implementations lack weights or licensing conditions.
For concrete models and families, `open` includes copyleft licenses and does not mean unlimited commercial use.
Unknown checkpoint licensing remains `license: null` and `weightAvailability: unknown`.
Code licensing alone is insufficient evidence for weight licensing.

Training datasets include documented pretraining and task training, not evaluation-only benchmarks.
Architecture and family lists can span the published reference variants and are not claims that every variant used every dataset.
The lists are not exhaustive.
Generic CNN has no unique training dataset, so its list is empty.
Country describes the credited research organization or research location, not an author's nationality.
`minPool`, family tokens, aliases, and broad category names are game/editorial metadata rather than independently measurable scientific properties.
Language-model context and reasoning fields retain the existing meaning: configured default context and dedicated reasoning mode, rather than maximum context after reconfiguration or general problem-solving ability.

## Scope and validation

The corrections target the requested category source file.
The merged `data/classic.seed.json` is edited by other concurrent work and was not regenerated by this review.
The normal merge processes other category files after Computer Vision, so overlapping general fields can be replaced by those files on a later merge.
Computer Vision-specific details remain owned by this source.
Split category files intentionally contain only their own `categoryDetails`, whereas the existing validator requires all focused-category details for a complete model.
Validation passed for a temporary Computer Vision-only projection of all 65 entries and a temporary overlay onto the full 294-entry catalog.
The projection removes other focused categories and their language-only optional fields; the overlay keeps the real categories and all category details.
`pnpm db:validate-seed`, targeted Prettier checks, and `git diff --check` also passed.
Entry IDs, aliases, names, family tokens, difficulty, and order were checked against the pre-edit snapshot and preserved.
